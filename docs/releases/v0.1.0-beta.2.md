# Operant v0.1.0-beta.2

这是 Operant 的第二个 Beta 源码预发布，适合愿意自行配置模型、从源码安装并反馈问题的开发者。
相比 beta.1，本版把多 Agent 协作、可视化编排、审批、经验复用和扩展能力接进日常工作流程。

**本次提供固定 Git 标签与 GitHub 源码归档，不含新的预编译桌面附件，也不发布到 PyPI。**
9 月 28 日的桌面候选属于旧版本，不能与本版 Core 混用。本版桌面仍需同源构建，尚无 Developer ID 签名、公证、DMG 或自动更新。

## 主要变化

- **从对话到协作**：在会话中委派子 Agent、发送定向消息并查看父子历史。子 Agent 按任务包工作，权限和预算受父任务约束，减少无关上下文传递。
- **工作流可以看见、编辑和运行**：画布支持节点、连线、版本差异与运行状态；14 类节点覆盖模型、工具、脚本、条件、循环、人工输入、审批、等待、子流程和工件等场景。对话生成的草稿需要确认后再发布。
- **审批严格度可选**：可以指定独立裁判模型，选择谨慎、平衡或宽松。超出范围的请求回到人工，硬性拒绝不能被模型覆盖，异常或超时不会自动放行。默认仍为人工审批。
- **经验可以积累，也可以纠正**：按任务召回有来源和版本的记忆，审阅候选、处理冲突与撤销；经验可以发布为 Skill，并显式共享给其他项目。后台整理默认关闭，不保证所有任务都节省 Token。
- **工作台更完整**：加入文件正文与 Diff、终端、配置继承、Goal/Plan/清单、旁路提问、上下文压缩，以及临时资源盘点和安全清理。
- **扩展与本机操作**：提供工具、命令、事件、Provider、Runtime、能力驱动六类本地扩展。GUI/TUI 可显式调用已授权命令与 Skill；macOS 可在授权范围内操作浏览器和指定 App，支持截图、剪贴板与人工接管。
- **私有跨设备任务**：macOS 与 Ubuntu 间支持设备配对、权限范围、加密命令与结果、断线追平、撤销，以及白名单约束的远端执行。未知写入结果不自动重放。
- **安装与日常修复**：六项默认 Skill 随 Core 分发；DOCX/PPTX/PDF 依赖可单独安装。补齐完整备份、隔离升级与回退，修复长任务记忆召回和退出 App 后自启 Core 残留。

## 从源码安装

准备 Git 和 uv，Python 要求 3.10+，开发版本由仓库 `.python-version` 指定。首次安装需要网络。

```bash
git clone --branch v0.1.0-beta.2 --depth 1 https://github.com/PinelliaChill/Operant.git
cd Operant
uv sync --frozen --extra dev
cp .env.example .env
uv run operant init
```

用编辑器在 `.env` 中填写模型服务地址和自己的 API Key，再查询可用模型：

```bash
uv run operant model discover
uv run operant serve --host 127.0.0.1 --port 8000
```

基础工作台位于 <http://127.0.0.1:8000/web>。按 [README](../../README.md#快速开始) 创建模型配置、角色和第一个只读任务。
需要完整 React 工作台时，另外准备 Node.js 22.6+ 和 npm，在第二个终端执行：

```bash
npm ci --prefix clients/gui
npm run dev --prefix clients/gui -- --host 127.0.0.1
```

访问 <http://127.0.0.1:3000> 并切换到 Live。默认演示模式的数据不是真实任务。
文档类 Skill 的可选依赖用 `uv sync --frozen --extra dev --extra artifacts` 安装；六项 Skill 还需在产品中显式安装、启用。
TUI 和桌面构建见 [TUI 说明](../../clients/tui/README.md)、[同源候选安装指南](../guide/candidate-installation.md)。

## 升级与回退

本版 SQLite Schema 为 **v23**。新用户优先使用新目录；已有用户先停止旧 Core/App，备份整个运行目录，在副本上升级。
备份不只包含数据库，还需包含记忆插件注册信息、包与外部工件。旧 Core 不可直接打开升级后的库。

v20/v22 到 v23 的隔离升级与从升级前完整快照回退已有验收；这不代表所有历史库都能无条件升级。
具体命令见 [升级与回退指南](../guide/candidate-installation.md#从旧版本升级并保留数据)。升级后应核对记录和插件状态，需要时显式重新启用插件。
发行操作不会更新本机已安装 App，也不会替用户迁移数据。

## 已知限制

- 仍为 Beta；没有签名公证桌面安装包、自动更新或公网部署验收。Windows 与任意 Linux 桌面环境不在本轮支持承诺内。
- Docker 条件跳过不算容器验收；Linux 第三方扩展隔离器和任意网站/App 操作不在本轮已验收范围。Host 模式使用当前系统用户权限，只用于可信工作区。
- 私有跨设备验收不等于可以直接把 Core 管理 API 暴露公网，也不等于通用远程桌面。
- 模型收到的提示词、代码和工具结果会传给相应模型服务。运行目录可能包含私有内容，反馈问题前请脱敏。
- 本次未升级依赖或集中修复存量安全告警；依赖更新继续通过独立 PR 验证。历史性能负结果与失败样本仍保留，不承诺统一的速度、Token 节省或成功率提升。

问题请提交仓库 Issue；安全漏洞通过 Security 页面私密报告。项目采用 Apache-2.0 许可证。
