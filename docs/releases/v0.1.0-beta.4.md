# Operant v0.1.0-beta.4

本版让首次使用从“先配置角色和运行”变为“连接模型，直接对话”，并提供自包含的 macOS arm64 DMG。
下载见 [GitHub Release](https://github.com/PinelliaChill/Operant/releases/tag/v0.1.0-beta.4)。

## 下载与开始使用

- `Operant-v0.1.0-beta.4-macos-arm64.dmg`：Apple Silicon Mac 安装包，内置 Python、Core 和运行依赖。
- 同名 `.sha256`：下载校验；来源摘要记录实际构建提交、输入和文件摘要。
- GitHub 的 Source code：固定发行标签的源码。

打开 DMG，将 Operant 拖入 Applications，再启动并连接模型。默认使用通用助手，连接后可直接发送任务。
API 方式填写服务商、密钥并选择模型；ChatGPT（Codex）方式使用已安装的官方 Codex CLI 完成账号登录，
该 CLI 不包含在 DMG 中。Gemini 支持 API 与 OAuth，OAuth 需要相应的 Google 桌面客户端及项目配置。
可用模型和参数以连接后的发现结果为准；不同连接的额度由服务商决定，订阅不等于所有 API 免费。

安装包采用 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。若系统阻止打开，可在系统设置的
“隐私与安全性”中核对应用来源后选择仍要打开。不要关闭整个系统的安全检查。

包内产品版本仍为 `0.1.0`，本次发行身份以 `v0.1.0-beta.4` 标签、构建源码和 SHA-256 为准。
使用正常产品身份及数据目录；验收用的独立候选包不会作为本版安装包上传。

## 主要变化

- **连接后即可对话**：自动准备个人工作区、默认模型和通用助手，保留规划、探索、编程、审查角色。温度、上下文及预算等高级参数默认收起。
- **对话有名称**：默认根据首条消息命名，支持手动改名；统一两个新建入口，修复每次新建误弹“已找到先前创建的对话”。
- **模型账号连接**：默认提供 ChatGPT（Codex）订阅连接，Operant 自己执行模型循环、工具和审批；原 ChatGPT 第三方授权保留在高级设置。Gemini API 与 OAuth 接入相同对话流程。
- **技能更容易使用**：扫描常见个人及工作区目录，支持标准 YAML、元数据、多行说明和受控链接；坏文件不会阻断其他技能，内置技能随工作区就绪。
- **界面与工具入口整理**：一级导航为对话、项目、协作、任务；配置集中于设置。统一选择控件，简化团队模板、工具和本机操作入口，移除日常界面的多余技术说明。
- **安装包与依赖修复**：当前源码的自包含 DMG 构建已纳入仓库；修复登录辅助进程写入签名 App 的缓存问题。更新 cryptography 与 source-map-js，具体版本见锁文件。

## 升级与数据

本版数据库为 SQLite Schema v26，Beta 3 使用 v23。升级前退出旧 App/Core，备份整个运行目录，
包括数据库、私有 `.env`、插件和外部工件；先在备份副本上验证，旧版 Core 不应打开升级后的库。
回退时恢复旧 App 与升级前的完整运行目录，不能只覆盖数据库文件。
操作说明见[安装、升级与回退](../guide/candidate-installation.md)。

本次发布只上传发行附件，不自动替换本机 App、迁移真实用户库、开通 Google 结算或改变模型套餐。
Core、GUI 和生成的 SDK 需成套升级，严格协议摘要握手保持启用。

## 已知限制

- 尚未 Apple 公证，没有自动更新；Windows、Linux 桌面和跨机器 Gatekeeper 行为未在本轮承诺范围内。
- 完整退出 App 会清空未发送草稿；在连接页与对话之间往返可保留草稿。
- 旧第三方 ChatGPT 授权的个人套餐及 Mountain 组织拒绝记录保留，不声称新 Codex 连接已改变原组织策略。
- TUI 新增自动刷新与撤销错误仍缺部分原生视觉记录；此发行不代表原始整理计划的全部验收完成。
- 8000 端口被其他服务占用时会拒绝启动，友好提示仍待改善；不要结束不明服务。
- 模型接收相应的提示词和工具结果；Host 工具使用当前用户权限，只对可信目录和明确授权目标开放。
