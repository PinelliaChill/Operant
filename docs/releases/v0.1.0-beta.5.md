# Operant v0.1.0-beta.5

本版修复项目切换、草稿恢复、权限提示和构建身份辨认中的实际使用问题。发行附件准备完成后在[GitHub Release](https://github.com/PinelliaChill/Operant/releases/tag/v0.1.0-beta.5)提供下载；未出现附件时不表示已发布。

## 主要变化

- 创建、重命名、归档或解除项目知识关联后，文件与对话页立即同步。文件页选择项目时同步当前工作区，文件、对话及协作页使用同步后的当前工作区；归档保留历史与文件读取。
- 草稿按服务来源、项目和对话保存，刷新或重开恢复。发送确认只清理提交的版本；发送后继续编辑、切换、失败或结果不确定均保留对应内容。原请求核对及冲突处理不会自动重发。
- 浏览器访问桌面专属管理功能时提示正确入口并禁用相关写操作；连接或模板读取失败不再误报为空。默认模型和就绪步骤区分读取未知、确实缺配置和已就绪。
- 无效项目路径给出中文纠错提示并保留输入；CLI的已知记录不存在错误简洁显示且非零退出，未知程序异常保留诊断。
- 设置页展示真实产品版本、发行标签、提交和候选身份。macOS资源定位支持临时目录别名与空格路径，来源身份不一致仍拒绝。

## 安装与数据

适用于Apple Silicon Mac。普通产品包为`Operant-v0.1.0-beta.5-macos-arm64.dmg`，同名`.sha256`提供下载校验，`来源摘要.json`记录精确源码与文件摘要。DMG只包含Operant和Applications入口，内置Python、Core及锁定依赖。将应用复制到Applications后启动；模型连接沿用[Beta 4说明](v0.1.0-beta.4.md#下载与开始使用)。

产品组件版本仍为`0.1.0`，发行标签为`0.1.0-beta.5`。候选包用于隔离验收，不作为普通安装附件。发布不会自动替换已有安装或迁移真实用户库；升级前退出旧App并备份完整运行目录，详见[安装、升级与回退](../guide/candidate-installation.md)。本轮未改变SQLite Schema v26或模型套餐。
